# Wiki

[Portal](../README.md) · [Sessions](../sessions/README.md) · [Collector](../collector.md)

`/wiki`는 포털의 기본 진입 화면이다. 현재는 빈 화면만 제공한다.

지식의 출처·검토·갱신 방식과 문서 모델, 편집·검색·권한·보관 정책은 다음 설계에서 정한다. 현재 Wiki는 세션을 수집하거나 분석을 실행하지 않는다.

Wiki 설계를 먼저 진행하고 그 요구에 따라 수집 경로와 Collector를 정한다. 기존 Sessions나 Collector를 그대로 재사용해야 한다는 전제는 두지 않는다.
